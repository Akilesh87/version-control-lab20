# Version Control Lab 20

## Project: Student Management System

This project demonstrates Git and GitHub version control for a team project.

## Branches

- main - Stable project branch
- student-module - Student management module
- course-module - Course management module
- testing-module - Testing and validation module

## Version Control Workflow

1. Create a module branch from main.
2. Make changes and commit them.
3. Push the branch to GitHub.
4. Create a Pull Request.
5. Review the changes.
6. Resolve conflicts when necessary.
7. Merge the Pull Request into main.

## Team Workflow

Each module is developed independently using a separate branch. Pull Requests are used for review before merging into the main branch.
